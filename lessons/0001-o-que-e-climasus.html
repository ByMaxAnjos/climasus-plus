O que é o climasus+

Você vai abrir o minicurso com esta ideia. Ela precisa ficar sólida antes de qualquer outra coisa, porque toda a linguagem do produto foi desenhada em volta dela.

A ideia central

climasus+ é um estúdio visual para montar e rodar análises de saúde, clima e ambiente do DATASUS — encadeando as funções do pacote climasus4r como um pipeline, sem o participante precisar saber que existe R por baixo.

"O público-alvo são profissionais de saúde/pesquisa que não sabem — nem precisam saber — programar em R."
— ADR 0001 — O Motor R é invisível

Essa é uma decisão deliberada, não uma limitação: se em algum momento da aula alguém perguntar "isso roda R?", a resposta correta não é explicar R — é reforçar que o participante nunca precisa saber disso. O detalhe técnico chama-se Motor, ponto.

Ao ensinar: nunca diga "engine", "script" ou "R" olhando para a tela do participante. Se aparecer na UI ("Motor R offline" etc.), é dívida de texto conhecida — não repita o erro na fala.

O modelo mental: Função → Passo → Nó → Pipeline

Quatro palavras carregam a estrutura inteira do produto. Nessa ordem, cada uma nasce da anterior:

1. Função
Uma operação do catálogo (ex: "Importar dados do DATASUS"). Só existe uma definição de cada — é o tipo. Fica na Biblioteca, esperando ser usada.
2. Passo
Quando o participante arrasta uma Função para o Pipeline e preenche seus parâmetros, ela vira um Passo — uma instância concreta daquela Função.
3. Nó
Cada Passo aparece na tela como um Nó no grafo. Um Passo = um Nó, sempre.
4. Pipeline
A sequência de Passos encadeados é o Pipeline — o que o participante efetivamente monta e executa.

Referência completa dos termos (incluindo Motor, Resultado, Etapa, Modelo...): Glossário climasus+.
