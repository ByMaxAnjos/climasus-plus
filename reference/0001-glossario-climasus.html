Referência rápida · climasus+

Glossário climasus+

Termos oficiais para usar no minicurso, exatamente como aparecem na interface. Fonte: CONTEXT.md. Sempre que dois termos parecerem sinônimos, use o canônico — nunca os termos em vermelho.

O pipeline e suas partes

Função
A definição de uma operação sus_* do catálogo, exibida na Biblioteca. Existe uma só de cada — é o tipo. Evite: bloco, ferramenta, comando.
Passo
Uma instância de uma Função dentro de um pipeline, com os parâmetros preenchidos — a instância. "Você adiciona uma Função e ela vira um Passo." Evite: bloco, card, node.
Nó
A representação visual de um Passo no grafo. Um Passo aparece como exatamente um Nó. Evite: card, caixa.
Pipeline
A sequência ordenada de Passos que o usuário monta e executa. Fica em inglês nos três idiomas. Evite: fluxo, grafo, canvas, workflow.
Projeto
Um Pipeline salvo em disco (.climasus.json). Projeto e Pipeline são a mesma coisa — "Projeto" é o nome do arquivo. Evite: arquivo, workspace, sessão.

Execução

Motor
Executa o Pipeline e devolve Resultados. Detalhe interno — a UI nunca revela que ele roda R. Ver ADR 0001. Evite: Motor R, engine, R, servidor.
Resultado
A saída de um Passo executado (tabela, gráfico, mapa, texto). Termo canônico voltado ao usuário. Evite: saída, output.
Artefato
O arquivo concreto de um Resultado (PNG, SVG, HTML interativo, CSV/XLSX). Sub-parte técnica — um Resultado-gráfico tem artefatos PNG, SVG e HTML. Evite: arquivo, download, asset.
Executar
A ação de rodar o Pipeline no Motor e produzir Resultados. Evite: rodar, run, processar.

Organização

Etapa
Uma das quatro fases didáticas de uma Função — Preparação, Integração, Análise & Modelagem, RAP. Organiza e colore a Biblioteca. Evite: fase, categoria, stage.
Biblioteca
O catálogo de Funções, agrupado por Etapa — de onde se arrasta uma Função para o Pipeline. Evite: catálogo, paleta, toolbox.
Modelo
Um Pipeline pré-montado que serve de ponto de partida editável (no código: "template"). Categorias: pipeline, clima, temático, caso. Evite: template, exemplo, receita, preset.
Tutorial
Experiência guiada, passo a passo, que ensina construindo um Pipeline. Diferente de Modelo: Tutorial conduz, Modelo só dá um ponto de partida. Evite: guia, walkthrough, tour.
Centro de Pipelines
O painel que lista os Modelos disponíveis e atalhos para Tutoriais. Evite: galeria, exemplos, templates.

Edição

Parâmetro
Cada entrada configurável de um Passo (ou Função) — o que o Inspetor edita. Mensagens de erro devem dizer "parâmetro", nunca "argumento". Evite: argumento, propriedade, opção.
Inspetor
O painel que edita os Parâmetros do Passo/Função selecionado. Evite: propriedades, config, editor.
climasus+
Nome do produto (com +, minúsculo). "Pipeline Studio" descreve o que ele é, não o nome. Evite: climasus Studio, climasu, Climasus+.
